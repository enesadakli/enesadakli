## 🚀 Featured Projects

| Project | What it does | Stack |
| :--- | :--- | :--- |
| **[agent-fleet-skills](https://github.com/enesadakli/agent-fleet-skills)** | Agent skills for running a multi-model coding fleet on ~$20/month plans — one orchestrator, cheaper models as delegate workers, with explicit cost routing. | `Shell` `Claude Code` `Codex` `Gemini` |
| **[kute-dating-app](https://github.com/enesadakli/kute-dating-app)** | Full-stack dating app: swipe discovery, JWT auth, real-time chat with typing indicators, and an AI "vibe analyzer" that reads conversation sentiment. | `React Native` `Expo` `Node.js` `Express` `MongoDB` `Socket.io` |
| **[spotify-taskbar-widget](https://github.com/enesadakli/spotify-taskbar-widget)** | A Spotify now-playing widget that docks inside the Windows 11 taskbar — album art, progress bar, and a live FFT audio spectrum gated to Spotify's own audio session. | `Python` `WASAPI` `Win32` |
| **[borsa-panel](https://github.com/enesadakli/borsa-panel)** | Local equity research panel: pulls BIST and US financial statements, then computes Piotroski F-Score, Altman Z-Score, earnings quality and inflation-adjusted real growth. | `Python` `JavaScript` `yfinance` |
| **[studyPad](https://github.com/enesadakli/studyPad)** | Tablet-pen note-taking app for students — pressure-sensitive canvas, page templates, undo history, autosave, and AI summaries / flashcards on top of lecture slides. | `React` `Fabric.js` `Tailwind` `Zustand` |
| **[passo-notifier](https://github.com/enesadakli/passo-notifier)** | Telegram bot that watches a ticket sales site and pings you the moment a match page opens or tickets drop. Deployed on Railway with anti-spam filtering. | `Python` `Telegram Bot API` `Railway` |
